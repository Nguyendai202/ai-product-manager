# coursera-notes

Ghi chú học chương trình IBM AI Product Manager (Coursera), viết bằng Eleventy và đăng lên GitHub Pages.

```bash
npm install && npm run serve
```

Mỗi bài trong `src/posts/` có front matter `course`, `module`, `order` (số tăng dần theo thứ tự học). Ghi chú diễn đạt lại bằng lời riêng; không chép transcript.
